# Sanity Setup Steps

## Step 1: Run Sanity Init

Run this command in your terminal:

```bash
npx sanity init
```

## Step 2: Answer the Questions

When prompted, use these answers:

1. **Create a new project or select an existing one?**
   - Select: **blog (sgfn7xbv)** (use arrow keys to select existing project)

2. **Select dataset to use**
   - Select: **Create new dataset**

3. **Dataset name:**
   - Type: **production**

4. **Choose dataset visibility**
   - Select: **Public (world readable)**

5. **Would you like to add configuration files for a Sanity project in this Next.js folder?**
   - Select: **Yes**

6. **Do you want to use TypeScript?**
   - Select: **No**

7. **Would you like an embedded Sanity Studio?**
   - Select: **No**

8. **Select project template to use**
   - Select: **Clean project with no predefined schema types**

9. **Would you like to add the project ID and dataset to your .env.local file?**
   - Select: **Yes**

10. **Configure Sanity MCP server?**
    - Select: **VS Code**

## Step 3: After Setup

After the setup completes, I'll help you:
1. Create the schema files for posts and authors
2. Update your code to use Sanity
3. Test the integration
